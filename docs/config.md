# 配置项

配置入口：`fcitx5-configtool` → 「虎虚」页。 \
设置页分「字集」「行为」「快捷键」三个分区。 \
选项详情可悬浮查看，保存写入 `~/.config/fcitx5/conf/hux.conf`。

![配置页](./images/配置页.png)

## 字集

主表码表 `tiger_sentence.codes.txt`（9,794 字）始终装载，追加码表
`tiger_sentence.codes.huma.txt`（生僻字；编排见 [`../data/README.md`](../data/README.md)）由下面两项决定；
「高频字过滤上限」也在本区（同属「哪些字参与组句」）。

| 项           | 默认 | 说明                                                         |
| ------------ | ---- | ------------------------------------------------------------ |
| 启用全字集   | 开   | 关闭只装主表码表（9,794 字，生僻字不再可打）；开启并装载追加码表，过滤非汉字后字集约 10.25 万字。代价：启动多约 0.13 s（满载约 140–156 ms）、常驻多约 88 MB。保存后即时生效（切换会重建词库，release 档约 0.15 s） |
| 过滤非汉字   | 开   | 过滤**追加码表**里落在 CJK 统一表意文字区段之外的符号（部首/笔画/注音/假名/兼容汉字等，现数据 939 条）；主表自带的标点/假名不受影响。保存后即时生效 |
| 高频字过滤上限 | 1500 | 仅最优码组句的高频字上限（0=不限；保存后即时生效）           |

装载结果随启动日志输出一行（`hux: data code_tables=[…] entries=… chars=… full_charset=… filter_non_han=…`），
「重新部署」后另输出一次——据此核对实际装了几张码表、两个字集开关的生效值。

## 行为（三态项 → 布尔项 → 值选项 → 其余枚举）

| 项                   | 默认     | 说明                                        |
| -------------------- | -------- | ------------------------------------------- |
| 提前上屏             | 至输出   | 三态下拉：**关闭** / **至输出**（证据成熟即提交当前候选）/ **至预编辑串**（写入预编辑缓冲，不直接提交） |
| 标点                 | 全角（常用） | 三态下拉：**ascii（all）**（标点不做中文映射，直接输出 ASCII）/ **全角（常用）**（常用标点输出全角）/ **全角（all）**（标点输出全角，如 `/` -> `／`） |
| 单字重码参与组句     | 开       | 允许同一单字的重码候选参与整句解码          |
| Tab 选字写入学习库   | 开       | Tab 选字时记录学习事件并参与排序            |
| 数字直选             | 开       | `1`–`9` 上屏当页候选，`0` = 第 10 个        |
| 翻页循环             | 关       | **末页再下翻回首页**（参照 `menu/page_down_cycle` 只作用于下翻；首页上翻恒停首页并归零高亮，见下） |
| 候选窗口显示预编辑   | 开       | 仅宿主显示项，不经引擎；状态菜单「虎虚」里可就地切换 |
| 提前上屏最短保留码数 | 0        | 0–20；与空码上屏共用，0 = 不额外限制        |
| 每页候选个数         | 5        | 1–10                                        |
| 候选排列             | 跟随全局 | 横排：↑↓ 选字、←→ 移动；竖排反之        |
| 预编辑内容           | 候选分码 | 候选分码（按词分段）/ 原始输入 / 不显示     |

> 两个三态下拉框与引擎的布尔开关一一对应（托盘「虎虚」里仍是独立勾选项，两侧读写同一批值）：
> 「提前上屏」= 关闭 / 至输出 / 至预编辑串 ⇒ `early_commit` 关·开·开、`early_commit_to_preedit` 关·关·开；
> 「标点」= ascii（all）/ 全角（常用）/ 全角（all）⇒ `ascii_punct` 开·关·关、`full_shape` 关·关·开。
> 改动前的四个布尔键（`Behavior/EarlyCommit` 等）不再读取：三个托盘角色由 `options.yaml` 兜住、
> 只有不进托盘的 `ascii_punct` 会回落到「全角（常用）」。
> 托盘与三态的一致性：托盘「虎虚」仍是独立勾选项，勾选态由引擎开关推出，故不会出现「勾了却显示中间态」；
> 三处耦合是有意为之——① 在「关闭」态勾「提前上屏至预编辑」会顺带打开提前上屏（⇒「至预编辑串」）；
> ② 关「提前上屏」会把「至预编辑串」一并关掉（回到「至输出」需再勾一次「提前上屏」）；
> ③ 标点为「ascii（all）」时「全角标点」未勾选，从该态勾上会落到「全角（all）」（不会回到 ascii）。

## 快捷键（`KeyList`，均可多项）

| 项              | 默认           | 说明                             |
| --------------- | -------------- | -------------------------------- |
| 音反查          | `` ` ``        | 拼音 -> 虎码                     |
| 字反查          | `~`            | 光标左侧汉字的拼音与虎码         |
| 上翻页 / 下翻页 | `-/=` 或 `[/]` | **菜单可见时上/下翻页同前置**：有候选（且非 `ascii_mode`）即判翻页并消费；PgUp/PgDn 始终可用。绑到此处的键在菜单可见时**优先翻页**（不被方案标点分支遮蔽——本仓有意偏离上游 `abad411`，见 [`upstream-deviations.md`](upstream-deviations.md) ①）；**代价（用户决定 B，2026-09）**：菜单可见时这几个键**不再能作为标点打出**（参照的 `when: paging`「已翻过页才生效」标签语义已按用户决定取消）；`ascii_mode` 或无菜单时仍按原路径落标点 |

反查触发键会被输入法消费：按下即进入反查（如 `` `zhongguo ``），不再作为普通字符输入。 \
`~` 是 Shift+`` ` `` 的字符，前端上报的是该 level 的 keysym（`asciitilde`），fcitx5 会去掉这种
「本身就产字符」键的 Shift，故默认值按无修饰的 `~` 声明；配置页里录到的也是同一形态。

配置文件 `~/.config/fcitx5/conf/hux.conf` 英文键名与 fcitx5 schema 对应。 \
快捷键为 fcitx5 `KeyList`，可配置多项；`AllowModifierLess` 允许无修饰键。 \
未显式提供的项跟随 fcitx5 全局设置（候选列表方向、客户端内联预编辑）。

## 选项与学习存储

- 选项：`~/.local/share/fcitx5/hux/tiger_sentence.options.yaml` \
  引擎的 7 个运行时开关（托盘「虎虚」子菜单：提前上屏、提前上屏至预编辑、单字重码组句、全角标点、
  数字直选、启用全字集、过滤非汉字）与配置页是**同一批值**：配置页侧把「提前上屏 + 提前上屏至预编辑」
  合并为三态「提前上屏」、把「全角标点」与不进托盘的「ASCII 标点直通」合并为三态「标点」。
  配置页保存时设置值写回本文件，状态菜单勾选时写入本文件并同步 `conf/hux.conf`
  ——任一侧改动都立即生效，另一侧立刻读到同一值。 \
  合并顺序：`options.yaml` 的值 > 设置 > 内建缺省；启动时 `conf/hux.conf` **显式写过**的共享键以
  该文件为准，没写过的键沿用 `options.yaml` 的现存值（宿主 `adoptStoredRuntimeOptions`）。 \
  兼容只读回退 `user.yaml` 的 `var/option/*`。
- 状态菜单「虎虚」子菜单除上面两批选项开关外，还有三项**宿主项**（不写 `options.yaml`）：
  「候选窗口显示预编辑」（写 `conf/hux.conf`，切换即时生效）、
  「重新部署」（重走一遍构造期的读取：数据/选项目录、模型、方案数据、选项存储与学习库，
  再重置全部会话，会话 id 不变；进程环境变量 `HUX_DATA_DIRS` / `HUX_MODEL` 在同一进程内不变）、
  以及一行模型信息 `模型：<状态>`（只报状态 + 格式标签 / 失败原因，不报文件名）。状态形如
  `已加载（三阶 TCSKNM02）` / `已加载（五阶 TCSKNM03）` / `未找到模型` / `装载失败：<原因>`。
- 学习库：`~/.local/share/fcitx5/hux/tiger_sentence_learning_<hash>.userdb/` \
  （LevelDB 同构，可直接迁移）
