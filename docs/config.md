# 配置项

入口：`fcitx5-configtool` →「虎虚」页（三区：字集 / 行为 / 快捷键，可悬浮查看）； \
保存到 `~/.config/fcitx5/conf/hux.conf`。

![配置页](./images/配置页.png)

## 字集

本区决定「哪些字参与组句」（文件见 [`../data/README.md`](../data/README.md)）：

| 项             | 默认 | 说明                                                         |
| -------------- | ---- | ------------------------------------------------------------ |
| 启用全字集     | 开   | 关闭只装主表（9,794 字）；开启（过滤非汉字）后约 10.25 万字  |
| 过滤非汉字     | 开   | 过滤**追加码表**中 CJK 统一表意文字区段之外的符号（939 条）  |
| 高频字过滤上限 | 1500 | 仅最优码组句的高频字上限（0 = 不限）                         |

- **启用全字集**：关闭后生僻字不可打；开启代价为启动 +0.13 s（满载 140–156 ms）、常驻 +88 MB。
- **过滤非汉字**：被过滤的是部首 / 笔画 / 注音 / 假名 / 兼容汉字等符号； \
  主表自带的标点 / 假名不受影响。
- 两个开关都保存即生效（切换会重建词库，release 档约 0.15 s）。

装载结果随启动日志与「重新部署」各输出一行 \
`hux: data code_tables=[…] entries=… chars=… full_charset=… filter_non_han=…`。

## 行为（布尔项 → 值选项 → 枚举 → 三态项）

| 项                   | 默认         | 说明                                                |
| -------------------- | ------------ | --------------------------------------------------- |
| 单字重码参与组句     | 开           | 重码候选参与解码                                    |
| Tab 选字写入学习库   | 开           | 记录学习事件并排序                                  |
| 数字直选             | 开           | `1`–`9` 上屏当页候选，`0` = 第 10 个                |
| 翻页循环             | 关           | **末页再下翻回首页**                                |
| 候选窗口显示预编辑   | 开           | 宿主显示项，不经引擎                                |
| 提前上屏最短保留码数 | 0            | 0–20；与空码上屏共用，0 = 不限                      |
| 每页候选个数         | 5            | 1–10                                                |
| 候选排列             | 跟随全局     | 横排 ↑↓ 选字、←→ 移动；竖排反之                 |
| 预编辑内容           | 候选分码     | 候选分码（按词分段）/ 原始输入 / 不显示             |
| 提前上屏             | 至输出       | 三态：**关闭 / 至输出 / 至预编辑串**                |
| 标点映射             | 全角（常用） | 三态：**关闭（半角） / 全角（常用） / 全角（all）** |

- **提前上屏**三态：**至输出** = 证据成熟即提交当前候选；**至预编辑串** = 写预编辑缓冲、不直接提交。
- **标点映射**三态：**关闭（半角）** = 不做中文映射、直接输出 ASCII； \
  **全角（all）** 如 `/` -> `／`。
- **翻页循环**：参照 `menu/page_down_cycle` 只作用于下翻；首页上翻恒停首页并归零高亮。

> 三态项 ↔ 引擎布尔开关：「提前上屏」⇒ `early_commit` 关·开·开、`early_commit_to_preedit` 关·关·开； \
> 「标点映射」⇒ `ascii_punct` 开·关·关、`full_shape` 关·关·开。 \
> `earlyCommitMode` / `punctMode` 是唯一真相，旧布尔键（`Behavior/EarlyCommit` 等）不再读取； \
> `ascii_punct` 不进托盘、回落到「全角（常用）」，另两个角色由 `options.yaml` 兜住；父项带当前值 \
> （`提前上屏：<当前态>`、`标点映射：<当前值>`），首项「虎虚」带模型状态。

## 快捷键（`KeyList`，均可多项）

| 项              | 默认           | 说明                                    |
| --------------- | -------------- | --------------------------------------- |
| 音反查          | `` ` ``        | 触发键（用法见 [`usage.md`](usage.md)） |
| 字反查          | `~`            | 触发键（同上）                          |
| 上翻页 / 下翻页 | `-/=` 或 `[/]` | **菜单可见时上/下翻页同前置**           |

- **上翻页 / 下翻页**：有候选（且非 `ascii_mode`）即判翻页并消费；PgUp/PgDn 始终可用；依据与代价见 \
  [`upstream-deviations.md`](upstream-deviations.md) ①。

反查触发键按下即进入反查、不再作为普通字符输入（如 `` `zhongguo ``）。`~` = Shift+`` ` ``， \
前端上报 keysym `asciitilde`；fcitx5 会去掉这种「本身就产字符」键的 Shift， \
故默认按无修饰的 `~` 声明。

`conf/hux.conf` 的英文键名与 fcitx5 schema 对应；`KeyList` 可多项 \
（`AllowModifierLess` 允许无修饰键）；未提供的项跟随 fcitx5 全局设置（候选列表方向、内联预编辑）。

## 选项与学习存储

- **选项** `~/.local/share/fcitx5/hux/tiger_sentence.options.yaml`（7 个运行时开关， \
  与配置页同一批值；两侧改动都写回本文件并同步 `conf/hux.conf`）、 \
  **学习库** `~/.local/share/fcitx5/hux/tiger_sentence_learning_<hash>.userdb/`（LevelDB 同构， \
  可直接迁移）：合并顺序、共享键取舍、`user.yaml` 回退见 [`resources.md`](resources.md) §10、 \
  [`../platform/README.md`](../platform/README.md)。
- **宿主项**（与首项「虎虚」同级，不写 `options.yaml`）：「候选窗口显示预编辑」 \
  （写 `conf/hux.conf`，即时生效）、「重新部署」（重走构造期读取、重置全部会话； \
  `HUX_DATA_DIRS` / `HUX_MODEL` 不变）。
- **模型信息并入首项「虎虚」**：`虎虚：<模型格式名>` / `虎虚：无模型` \
  （装载失败 `<格式名>（装载失败）`）；**点击该项打开模型所在目录**（无模型时打开默认放置目录， \
  必要时新建并在 `hux:` 日志留路径）；见 [`resources.md`](resources.md) §2。
