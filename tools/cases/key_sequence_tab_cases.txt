# `goldens/key_sequence_tab/tiger_sentence.custom.yaml`（`tiger_sentence/tab_learning: true`）
# ⇒ 真机 librime 里参照的学习库**就绪**（`learned.store.db` 非 nil），
# 于是参照处理器走 `if not state.tab_pending and learned.store and learned.store.db then
#  _, first = learning_selection(...) ; learned.baseline = first end` 这条分支。
# 主金样（`key_sequence.tsv.gz`）的夹具是 `tab_learning: false`，该分支恒不进入。
#
# 格式：<名称>\t<重置选项（逗号分隔，可空）>\t<按键 repr 序列（空格分隔）>
# 重置固定：clear_composition、ascii_mode=false、tiger_sentence_early_commit=1、
# tiger_sentence_early_commit_to_preedit=0；其余选项由第二列覆盖。
